# Ecommerce Application

## Purpose
This repository contains a brown-field style e-commerce application
used as a foundation to run and validate future agentic AI use cases
across UI, API, and Database layers.

## Functional Scope
- User Login
- User Profile
- Product Search
- Cart Management

## Technology Stack
- Angular (UI layer)
- Spring Boot (API layer following MVC)
- Relational Database (PostgreSQL recommended)

## Repository Structure
ui-angular/      Angular frontend application  
api-springboot/  Spring Boot backend services  
db/              Database DDL, DML, and query scripts  
docs/            Architecture and design documentation  

## Testing Strategy
A dedicated test automation framework will be introduced later.
Test assets are intentionally excluded at this stage to keep the
initial setup lightweight and flexible.
